# ServerLab AI — толық жоба 2.4

**Сайт авторы: Ақшабаева Сымбат.**

Бұл — сайт құрастырушыға жазылымсыз компьютерде өңдеп, Node.js арқылы іске қосуға болатын толық бастапқы код.

## Не бар?
- 12 модуль, 36 сабақ: сервер архитектурасы, CPU/RAM/ECC, HDD/SSD/NVMe, RAID және backup, желі, виртуализация/Docker, қауіпсіздік, мониторинг, дата-орталық, Linux/Windows Server, веб/деректер базасы/API, жоғары қолжетімділік және диагностика.
- Әр сабақта түсіндірме, мысал, практика, тест; тесттен кейін XP және мотивациялық терезе. Әр сабаққа бейне ресурс іздеу сілтемесі, бірнеше модульде ендірілген видео бар.
- Тіркелу және кіру, жеке прогресс, тест нәтижелері мен XP.
- Әкімші панелі: білім алушылар тізімі, топ/сынып бойынша сүзу, прогресс, тест нәтижелері және CSV экспорт. Тіркеу арқылы ешкім әкімші бола алмайды; әкімші рөлі сервердегі жеке `ADMIN_EMAIL`/`ADMIN_PASSWORD` параметрлері арқылы ғана беріледі.
- KZ/RU/EN тіл ауыстырғышы. Негізгі интерфейс жазулары офлайн сөздікпен аударылады. Ұзын сабақ мәтіндерінің автоматты аудармасы сервердегі `OPENAI_API_KEY` болса іске қосылады; кілтсіз толық динамикалық аударма жасалмайды.
- Сервер конфигурациясы зертханасы және ИИ-тәлімгер. `OPENAI_API_KEY` болмаса, сайттың қалған бөлігі істей береді, ИИ жауабы демонстрациялық режимде болады.

## Windows-та ең оңай іске қосу
1. Node.js 20 немесе одан жаңа нұсқасын орнат: https://nodejs.org/
2. Осы папканы Visual Studio Code-та аш.
3. `Terminal` → `New Terminal` таңда.
4. Командаларды орында: `npm install`, содан кейін `npm start`.
5. Браузерде http://127.0.0.1:4173 аш.

### Жергілікті әкімші аккаунты
1. `.env.example` файлын көшіріп, сол папкада көшірмесін `.env` деп ата.
2. `.env` ішіндегі `ADMIN_EMAIL` мәнін өз email-іңе, `ADMIN_PASSWORD` мәнін өзің білетін кемінде 12 таңбалы жеке құпиясөзге өзгерт. `ADMIN_NAME=Ақшабаева Сымбат` деп қалдыруға болады.
3. `npm start` командасын қайта орында.
4. Сайтқа сол email мен құпиясөзбен кір. Құпиясөзді чатқа жіберме және GitHub-қа `.env` файлын жүктеме.

## Деректер базасы қалай жұмыс істейді?
- `DATABASE_URL` бос кезде әзірлеушіге арналған жергілікті JSON сақтау режимі іске қосылады. Тіркелу, кіру, progress және admin API-ді жергілікті тексеруге болады. Дерек `.localdata/serverlab-store.json` файлына жазылады. Бұл — жергілікті даму режимі, бірнеше құрылғыға ортақ бұлт базасы емес.
- Нақты жарияланған сайтта тұрақты ортақ аккаунттар үшін PostgreSQL керек. Render-де PostgreSQL жаса, `Connect` бөліміндегі **Internal Database URL** мәнін веб-сервистің **Environment** ішіндегі `DATABASE_URL` айнымалысына қой. Web service пен база бір аймақта болуы керек. Render Free веб-сервисінің файлдары рестарт/ұйқы/деплойдан кейін жоғалуы мүмкін, сондықтан Render-де `local-file` режимін нақты оқушылардың тұрақты деректеріне пайдаланба.
- Сервер кестелерді автоматты түрде жасайды. Қосу күйін `https://сайт-адресі/api/status` арқылы тексер: PostgreSQL режимінде `dbConfigured:true`, `dbConnected:true`, `storageMode:"postgresql"` болуы қажет.
- Render командалары: Build `npm install`; Start `npm start`; Root Directory бос, егер осы файлдардың бәрі репозиторий түбірінде болса.

## Жеке Environment айнымалылары
- `DATABASE_URL` — PostgreSQL URL, құпия.
- `ADMIN_EMAIL` — әкімшінің email-і.
- `ADMIN_PASSWORD` — кемінде 12 таңбалы құпиясөз.
- `ADMIN_NAME` — `Ақшабаева Сымбат`.
- `OPENAI_API_KEY` — ИИ және толық динамикалық аударма үшін optional құпия кілт. Оны GitHub кодына жазба.
- `OPENAI_MODEL` / `TRANSLATION_MODEL` — модель параметрлері, әдетте өзгерту қажет емес.

## Қауіпсіздік және шектеулер
- Құпиясөздер plain text күйінде сақталмайды — scrypt хэші сақталады. Сессия токенінің хэші ғана базаға жазылады.
- Білім алушының email-ін, оқу нәтижесін тек оқу мақсатында және рұқсаты бар адамдарға ғана көрсет.
- Render Free PostgreSQL базалары 30 күннен кейін мерзімі бітеді; ұзақ мерзімді пайдалану үшін тиісті тұрақты сақтау жоспары керек: https://render.com/docs/free
