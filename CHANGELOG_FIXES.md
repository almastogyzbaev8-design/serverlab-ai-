# ServerLab AI 2.4 — исправления по замечаниям

- Исправлен блокирующий сценарий при отсутствии `DATABASE_URL`: локальный запуск теперь использует локальную JSON-базу, и можно проверить регистрацию, вход, прогресс и админ-API без PostgreSQL.
- В облаке возвращён явный статус `storageMode` и предупреждение: локальный JSON не является постоянной общей базой для Render. Для реальных групп и нескольких устройств необходим `DATABASE_URL` PostgreSQL.
- Регистрация не позволяет выбрать роль администратора. Администратор создаётся/назначается только через секретные `ADMIN_EMAIL` и `ADMIN_PASSWORD` в окружении сервера.
- Проверены маршруты регистрации, входа, выхода, чтения/сохранения прогресса, статуса базы и выдачи учеников администратору.
- Добавлена загрузка локального `.env` через optional `dotenv`; если пакет ещё не установлен, сервер всё равно может запуститься в локальном режиме.
- Добавлены офлайн-переводы названий 12 модулей и 36 тем на русский и английский, а также ключевых интерфейсных надписей. Перевод длинного текста уроков на лету требует `OPENAI_API_KEY`.
- Сохранены 12 модулей и 36 содержательных уроков, тест из трёх вопросов в каждом уроке, видео-ресурсная ссылка по теме, XP, мотивационное окно после теста, серверная лаборатория, игры и дизайн в тематике серверов/дата-центров.
- В проекте и подписях используется «Білім алушы». Автор сайта указан как «Ақшабаева Сымбат».
- Добавлена документация `README_START_RU.md` с простым запуском в Windows/VS Code и `README.md` с настройкой Render/PostgreSQL.

## Важные ограничения

- В режиме `local-file` данные находятся только на этой установке и сохраняются в `.localdata`; он предназначен для локальной демонстрации и не заменяет PostgreSQL на публичном хостинге.
- Секретные параметры нужно вводить только в `.env` локально или в Environment Render. Не загружайте `.env` в GitHub.
- Если нет `OPENAI_API_KEY`, сайт работает без генеративных ответов ИИ и без автоматического перевода длинных параграфов; офлайн-словарь интерфейса и заголовков продолжает работать.
